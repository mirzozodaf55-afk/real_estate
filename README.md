# Domly — аренда и продажа недвижимости в Таджикистане

Две части в одном репозитории:

| Папка | Что это | Стек |
|---|---|---|
| `Nuxt-project/` | сайт (SPA) | Nuxt 3, Vue 3, Tailwind |
| `laravel/` | API | Laravel 10, MySQL, Sanctum, laravel-websockets |

ИИ — Groq (OpenAI-совместимый API), карты — Яндекс Карты. Устройство системы, таблицы и эндпоинты — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск для разработки

```bash
# API
cd laravel
composer install
# создать .env (шаблона в репозитории нет): БД, почта, ключи — см. таблицу ниже
php artisan key:generate
php artisan migrate
php artisan db:seed           # справочники: города, инфраструктура, удобства
php artisan serve --host=0.0.0.0 --port=8000
php artisan websockets:serve # уведомления и чат в реальном времени
php artisan schedule:work    # ежедневная чистка просроченных токенов

# Сайт
cd Nuxt-project
npm install
npm run dev                  # http://localhost:3000
```

Сайт сам определяет адрес API по адресу, с которого открыт (работает и по IP в локальной сети).

### Тесты

```bash
cd laravel
mysql -e "CREATE DATABASE announcement_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"  # один раз
php artisan test
```

Тесты работают с отдельной базой `announcement_test` (задана в `phpunit.xml`) и каждый раз очищают её.
На базе с другим именем они останавливаются до очистки (`tests/RefreshTestDatabase.php`), поэтому рабочие данные
не пострадают даже при закешированном конфиге. ИИ, почта и websocket в тестах не вызываются.

Что проверяется (`tests/Feature`):
- `AccessControlTest`: гость, пользователь, модератор, админ и заблокированный видят только своё;
  удалённые небезопасные маршруты не вернулись; выводы ИИ не видны публично; файлы не отдаются за пределами папок.
- `ModerationTest`: одобрение, отказ, доработка, массовые действия, повторный клик, порядок очереди;
  правка одобренного объявления возвращает его на проверку.
- `AutoModerationTest`: режимы off / approve / full, дубликаты ждут модератора, устаревшая проверка ИИ не учитывается.
- `PrivateChannelsTest`: на переписку и уведомления подписываются только их участники.
- `ProfileSecurityTest`: смена почты только по коду с новой почты, перебор кода, тип аватара определяется по содержимому.

### Ключи в `laravel/.env`

Все секреты — только в `.env`, в репозиторий он не попадает.

| Переменная | Зачем |
|---|---|
| `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL` | ИИ (Groq): помощник, тексты, проверка объявлений |
| `OPENAI_VISION_MODEL` | ИИ-проверка фото (пусто — выключена) |
| `OPENAI_CA_BUNDLE` | файл корневых сертификатов для PHP на Windows |
| `GOOGLE_CLIENT_ID` | вход через Google (в Google Cloud добавить origin сайта) |
| `APPLE_CLIENT_ID`, `APPLE_REDIRECT_URI` | вход через Apple (нужен домен с HTTPS) |
| `SANCTUM_EXPIRATION` | срок токена входа в минутах (по умолчанию 30 дней) |
| `FRONTEND_URL` | адрес сайта для ссылок в письмах |
| `MAIL_*` | отправка писем (коды входа, решения модерации) |

### Роли

Роль меняет администратор в админке («Пользователи») или командой:

```bash
php artisan user:role you@example.com admin   # admin | moderator | user
```

## Модерация: этап 1

Что есть: очередь с сортировкой по риску ИИ, фильтры по риску/статусу/дате, готовые причины отказа (редактирует админ),
статус «на доработку», массовые действия, поиск дубликатов по фото (pHash) и тексту.

### Для уже существующих объявлений

Новые объявления проверяются сами после подачи. Для поданных раньше:

```bash
php artisan moderation:backfill --hashes   # pHash фото (без ИИ, быстро)
php artisan moderation:backfill --ai       # ИИ-проверка текста и цены для ожидающих модерации
```

### Демо-данные

```bash
php artisan db:seed --class=ModerationDemoSeeder   # 6 демо-объявлений с разным риском, дубликат, «на доработке»
php artisan moderation:demo-clear                  # убрать их (только владельцы demo-…@example.invalid)
```

### Как проверить

1. Войти как модератор или админ → «Админка» → «Модерация».
2. Очередь «На проверке»: сверху «Высокий» риск, ниже «Средний», «Низкий», «Не проверено». Фильтры — над списком.
3. Открыть объявление: блоки «Проверка ИИ» и «Возможный дубликат», кнопки «Одобрить», «На доработку», «Отклонить».
4. «Отклонить» → выбрать готовую причину или «Другое» со своим текстом. Владелец получит уведомление и письмо с кнопкой «Исправить объявление».
5. Отметить несколько объявлений галочками → «Одобрить» / «Отклонить».
6. Админ: «Причины отказа» — добавить, изменить, выключить, удалить.
